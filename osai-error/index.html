Why am I experiencing errors with OSAI?



OSAI is my implementation of serving open source AIs through the internet with a privacy-first approach. No log on is required, your data is encrypted, is not stored or shared to third parties and is inaccessible even by me.



When you use OSAI, it makes an API call to my server. If you are using company hardware your company most likely has disabled API calls to unknown internet sources - which, honestly, is a good security measure to protect against internet threats.

But it does also mean, that my server https://gmserver.xyz will be automatically blacklisted, as it is an unknown domain + I’ve connected it to the internet rather recently.

Unfortunately, getting OSAI to work on your work hardware is not worth the time.
I suggest trying it out on your personal devices - such as a personal phone or PC, as my server is freely listening to requests from the internet.

My server is a completely local solution. I assembled the hardware myself and it runs on a fresh install of Ubuntu. Your chat history is not recorded. Whatever you write to any of the large language models and their response, is for your eyes only. The conversations you have with the models are inaccessible even by me. Data is encrypted from your machine to my server end-to-end with https.



The website acts as a gateway to an API that I built using Go, data in transit is encrypted end-to-end with Cloudflare, also providing DDOS protection.
